  • Hands-on SRE: defined SLIs and SLOs (Sloth, Prometheus, Alertmanager, multiwindow burn-rate, error budgets) for components that had no metrics at all — with instrumentation, paired runbooks and GitOps delivery.
  • Achei os SLOs que não mediam nada: alertas em no-op por convenção de nome do exportador OpenTelemetry e runbooks que consultavam regras inexistentes. Cada classe de erro virou validação no CI, não correção pontual.
  • Found the SLOs that measured nothing: alerts silently no-op'd by an OpenTelemetry exporter naming convention, runbooks querying rules that didn't exist. Each class of bug became a CI check, not a one-off fix.
  • Concorrência em worker gRPC assíncrono: isolei estado entre execuções (ContextVar) e tirei chamadas bloqueantes do event loop. Vazamento de sessão entre execuções caiu de 39% para 0 em mais de 32 mil amostras de produção.
  • Concurrency in an async gRPC worker: isolated per-execution state (ContextVar) and moved blocking calls off the event loop. Cross-execution session leakage dropped from 39% to 0 across 32k+ production samples.
  • Migração de plataforma: conduzi parte da migração de crawlers de jobs Kubernetes para um worker gRPC — diagnóstico com Prometheus e Loki, separando causa raiz de ruído e evitando rollbacks desnecessários.
  • Platform migration: drove part of the move of crawlers from Kubernetes jobs to a gRPC worker — Prometheus and Loki diagnostics, separating root cause from noise and avoiding needless rollbacks.
